## 2026-10-07 — `OOP_20261007-230107_TFS` — TFW Full setup for the OOP mini-LMS

**Что принято.** Проект WEBOOP переведён на TFW Full 3.9.0: конфигурация получателя, профиль
владельца, Project North Star в `README.md`, чистая запись `KNOWLEDGE.md`, codex-совместимый адаптер
из 11 команд, каталог задачи с полным набором из девяти полей маршрутизации, замороженный контракт
(HL) и проверяемый baseline.

**Что изменилось по ходу.** Инициализационное исследование в двух итерациях закрыло пять гипотез:
H2 и H3 подтверждены, **H4 опровергнута** (статического анализа недостаточно, поведение требует
исполнения), H5 подтверждена, **H1 осталась непроверенной** — сопоставимого источника нет, объём
курса проверяется измерением при реализации недели 1. Утверждены три правки контракта (A1–A3):
исследование в объёме задачи, глубина курса через исправление готового кода, клиентская модель
баллов с обязательным уведомлением студента.

**Измерено, а не взято из документации.** Первая загрузка `pyodide-core` 314.0.7 в Chrome 154:
**6.10 MiB со сжатием gzip / 12.92 MiB без сжатия**, около **2 с** до готовности рантайма,
**CPython 3.14.2**, `micropip` не нужен. Документированное число `6.4 MB` подтвердилось.

**Ошибка, которая была поймана до публикации.** Первый замер шёл через `python -m http.server`,
который не ставит `Content-Encoding`, и был сравнён со сжатой цифрой из документации; из этого был
сделан ложный вывод «документация занижена вдвое». Независимый review вскрыл инверсию, замер был
повторён со сжатием, вывод отозван. Подробности — `KR-OOP-0001` и `REVIEW__…__rev1.md`.

**Закрытие отложения (DoD 11).** Идемпотентность повторной установки адаптера подтверждена прямой
проверкой `/tfw-update` против закреплённого источника `v3.9.0`: 0 расхождений по байтам для всех
11 команд адаптера (квитанция `.tfw/update_receipts/UPDATE__20261008-004832__b7c1.md`, строка EV E24).
Все критерии задачи подтверждены, задача завершена (`DONE`).
