# WEBOOP — мини-LMS для изучения ООП

Учебный веб-проект: короткий курс по объектно-ориентированному программированию для студентов
второго курса. Сайт работает локально, без деплоя.

## Зачем этот проект

Студенту второго курса нужен короткий и понятный курс по ООП, который можно пройти от начала до
конца за три недели и получить за это баллы. Материал должен быть не набором слайдов, а рабочим
маршрутом: объяснение, визуализация, практика, автоматическая проверка кода и тесты.

Проект решает две задачи одновременно. Первая — дать студенту цельный маршрут изучения ООП.
Вторая — быть учебным полигоном: автор проекта сам студент второго курса, который осваивает
методологию Trace-First Workflow (TFW) в полной версии.

## Что здесь строится

**Продукт:** локальный веб-сайт с курсом по ООП из трёх недель.

| Параметр | Значение |
|---|---|
| Аудитория | студенты второго курса |
| Длительность | 3 недели |
| Лекции | 1 час в неделю |
| Практика | 1 час в неделю |
| Домашнее задание | около 1 часа в неделю |
| Итог | экзамен; формат определяется по ходу работы |
| Формат сдачи | баллы за пройденный курс |
| Развёртывание | локальный запуск, без деплоя |

**Содержимое каждой недели:** лекционный материал, визуализация понятий, практическое задание,
автоматическая проверка кода и тесты для самопроверки.

**Прогресс студента:** курс проходится от начала до конца; за выполненные шаги начисляются баллы.

## Что проект не должен делать

Проект должен остаться понятным, маленьким и локальным. Он не должен превращаться в:

- промышленную LMS с ролями, администрированием, расписанием и интеграциями;
- платформу с реальной аутентификацией, базой данных под нагрузкой и облачным деплоем;
- сборник несвязанных демонстраций вместо последовательного курса;
- источник непроверенных утверждений о качестве обучения.

## Как устроена работа

Проект ведётся по методологии **Trace-First Workflow (TFW), редакция Full 3.9.0**. Ядро
методологии лежит в `.tfw/`. Каждая задача живёт в собственном каталоге под `workspace/<год>/`
и хранит собственный след: контракт (HL), исследование (RES), задание (TS), отчёт о выполнении
(RF), доказательства (EV) и независимую проверку (REVIEW).

| Что | Где |
|---|---|
| Философия и методология | `.tfw/README.md` |
| Правила и соглашения | `.tfw/conventions.md` |
| Термины | `.tfw/glossary.md` |
| Рабочие процессы | `.tfw/workflows/` |
| Формы артефактов | `.tfw/templates/` |
| Конфигурация проекта | `.tfw/project_config.yaml` |
| Проверенные знания | `KNOWLEDGE.md` |
| Участники | `team/` |
| Задачи | `workspace/<год>/<ID>/` |

**Статус проекта:** инициализация TFW выполняется в задаче
`workspace/2026/OOP_20261007-230107_TFS/`. Архитектура продукта ещё не спроектирована.
