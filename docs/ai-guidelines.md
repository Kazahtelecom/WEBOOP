# Памятка для ИИ-агентов и разработчиков (AI Guidelines)

Этот документ — главный входной справочник для любого ИИ-агента (Antigravity, Cursor, Claude Code, Copilot и др.), подключающегося к репозиторию **WEBOOP**.

---

## 1. Миссия и границы продукта (North Star)
- **Что строим:** Локальную мини-LMS для 3-недельного курса по ООП для второкурсников.
- **Темы курса:**
  - Неделя 1: Классы, объекты, инкапсуляция.
  - Неделя 2: Наследование и композиция.
  - Неделя 3: Полиморфизм и абстракции.
  - Финал: Практический экзамен (поиск и исправление багов в коде).
- **Вне границ (НЕ ДЕЛАТЬ):**
  - Никаких серверов, баз данных (Postgres, MongoDB), авторизации с паролями, бэкендов на Node/FastAPI.
  - Никаких тем из недель 4–9 (SOLID, паттерны GoF, потоки) — они вынесены за рамки текущего продукта.

---

## 3. Золотые правила для ИИ-агента

### Правило 1: Строгая типизация
- Запрещено использовать `any`.
- Все контракты данных уроков и состояния брать строго из `docs/domain/model.md` и `src/types/`.

### Правило 2: Изоляция Pyodide в Web Worker
- Никогда не запускать Pyodide прямо в основном потоке React.
- Любое выполнение кода студента оборачивать в таймаут 5 секунд (`terminate()` при превышении), чтобы предотвратить зависание вкладки.

### Правило 3: Local-first сохранность данных
- Любой прогресс, баллы и набранный студентом код должны мгновенно сохраняться в `localStorage`.
- Студент не должен терять набранный код при случайном обновлении страницы (`F5`).

### Правило 4: Чистота Git и репозитория
- Запрещено добавлять бинарные файлы (PDF, большие архивы, дампы) в git. Они находятся в `.gitignore`.
- Перед коммитом всегда проверять компиляцию и отсутствие ошибок типов:
  ```powershell
  npm run typecheck
  npm run lint
  ```
