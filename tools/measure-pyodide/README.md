# Стенд замера цены Pyodide

Измеряет фактическую цену первого запуска Python в браузере для релиза `pyodide-core` **314.0.7**.
Существует потому, что числа `6.4 MB` и `4–5 с` в документации Pyodide принадлежат версии документации
**0.19.1** и для 314.0.7 не подтверждены (HL §9 R9). Продуктовой ценности стенд не несёт: он
классифицирован как `ASSURANCE`, а не `VALUE`.

## Что измеряется

| Метрика | Как получается | Почему важна |
|---|---|---|
| Объём раздачи | Сумма распакованных файлов архива `pyodide-core-314.0.7.tar.gz` | Оценка объёма, который нужно раздавать |
| Переданные байты | Chrome DevTools Protocol, домен `Network`, поле `encodedDataLength` | Честный объём по сети, с учётом сжатия |
| Время инициализации | `performance.now()` вокруг `loadPyodide()` в самой странице | То, что почувствует студент |

## Три факта, без которых число не является измерением

Записывать обязательно, иначе результат нельзя сравнивать:

1. **Браузер и версия** — замеры в разных браузерах не сравнимы.
2. **Состояние кеша** — первая загрузка и повторная дают разные числа; продуктовой задаче нужна первая.
3. **Сжатие** — передаются brotli/gzip или сырые байты; `encodedDataLength` уже учитывает сжатие.

## Как воспроизвести

### Шаг 1. Скачать раздачу локально

```
python fetch_core.py
```

Скрипт использует только стандартную библиотеку Python (`urllib`, `tarfile`) и кладёт файлы в
`vendor/pyodide-core/`. Версия закреплена в скрипте и в этом README.

### Шаг 2. Раздать статически

```
python -m http.server 8801 --directory .
```

Сервер разработчика не требуется: достаточно статической раздачи
([документация Pyodide](https://pyodide.org/en/stable/usage/downloading-and-deploying.html)).

### Шаг 3. Замерить

```
node measure.mjs
```

`measure.mjs` запускает уже установленный Chrome или Edge в headless-режиме, подключается к нему
по Chrome DevTools Protocol через встроенный в Node клиент `WebSocket` (**внешних зависимостей нет**)
и печатает отчёт.

Опции:

```
node measure.mjs --port 8801 --url http://127.0.0.1:8801/index.html --browser auto --runs 2
node measure.mjs --browser "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

## Честные ограничения стенда

- **Первый заход харнесса прогревает кеш.** Скрипт запускает браузер с отдельным временным
  профилем, поэтому первый прогон в сессии — первичный; повторные прогоны в том же профиле
  прогреты, и это напечатано в отчёте.
- **Сеть до CDN измеряется как есть.** Объём зависит от того, отдаётся ли brotli; стенд не
  контролирует CDN и не подменяет ответ.
- **Замер времени включает инициализацию рантайма, но не написание кода студентом.** Это цена
  старта, а не цена работы.
- **`runs: 2` по умолчанию** — первое число и повтор дают разброс; отчёт печатает оба.

## Что делать с результатом

Числа записываются в `evidence/EV__OOP_20261007-230107_TFS.md` в строку AC-10 вместе с браузером,
версией, состоянием кеша и методом. Если браузер недоступен, фиксируется `BLOCKED` с точной
причиной; **подменять число значением из документации запрещено** (TS §7).
