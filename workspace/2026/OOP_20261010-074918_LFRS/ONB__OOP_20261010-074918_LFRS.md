## 1. Understanding

Задание требует развернуть и верифицировать автономный клиентский фундамент мини-LMS **WEBOOP**:
1. Инициализировать проект на React 18/19, TypeScript (strict), Vite, Tailwind CSS без внешнего бэкенда и БД.
2. Реализовать строгие доменные интерфейсы из `docs/domain/model.md` в `src/types/course.ts` и протокол сообщений в `src/types/worker.ts` без использования типа `any`.
3. Создать изолированный Web Worker с рантаймом Python (`pyodide` WASM CPython 3.14), перехватом потоков вывода и защитным сторожевым таймером на 5 секунд.
4. Разработать реактивное хранилище Zustand с сохранением набранного кода студента, баллов и статусов задач в `localStorage`, а также экспортом/импортом в JSON.
5. Реализовать двухпанельный UI (SplitPane): левая панель — теория, правая — редактор CodeMirror 6 и консоль вывода/тестов, сайдбар навигации по курсу и шапка с баллами.
6. Включить минимальный демо-модуль (1 задача на класс `Counter`) для сквозного тестирования исполнения, прохождения тестов и начисления баллов. Учебные материалы Недели 1 в задачу не входят.

## 4. Recommendations (suggestions, not blocking)

1. **Изолированная инициализация:** Создать манифест и конфигурации вручную или через точечное развертывание, чтобы гарантированно не затронуть существующие системные папки `.tfw/`, `docs/`, `workspace/`, `team/`.
2. **CDN для Pyodide:** Загружать `pyodide.js` через jsDelivr CDN (`https://cdn.jsdelivr.net/pyodide/v0.26.4/full/pyodide.js`) в Web Worker, что предотвратит раздувание бандла Vite десятками мегабайт WASM-бинарников.
3. **Легковесный редактор:** Использовать `@uiw/react-codemirror` и `@codemirror/lang-python` — это стандартный, надежный и легковесный редактор с полноценной подсветкой Python.
4. **Надежный сторожевой таймер:** Реализовать фабрику воркера `createPyodideWorker()` в хуке/сервисе, чтобы при срабатывании 5-секундного таймаута безопасно вызывать `worker.terminate()` и сразу пересоздавать свежий экземпляр.

## 5. Risks Found (edge cases, potential issues not in TS)

1. **R-1: Сетевая доступность CDN в среде разработки:** Первый запуск Pyodide требует скачивания ~6.1 МБ с CDN. Если сеть нестабильна, рантайм вернет ошибку загрузки. Митигация: явная индикация статуса подключения и загрузки Pyodide в консоли/терминале.
2. **R-2: Vite Worker module bundling:** Особенности сборки Vite для Web Worker модулей. Митигация: использовать нативный синтаксис `new Worker(new URL('../workers/pyodide.worker.ts', import.meta.url), { type: 'module' })`.
