**Operational effect.** AC-10 becomes executable in this session. The Executor may drive the
already-installed Chrome or Edge through the Chrome DevTools Protocol using Node's built-in
`WebSocket` client, obtaining transferred bytes from the Network domain and initialization time
from the page. **No new package, dependency or file is added**: the owner's automated choice is
delivered without `npm install`, which matters because `npm` does not resolve as a command in
this environment (ONB risk R-A). The approved TS file set and the accounting denominator of zero
`VALUE` files both remain unchanged.

an owner reservation, so it is a valid `gate_answer` and does not require a TS revision. The
measurement harness remains confined to `tools/measure-pyodide/`.

**Recorded constraint.** The measured numbers must name the browser and version, the cache state
(first load versus repeat) and whether transferred bytes were brotli-compressed. A number without
those three facts is not a measurement.
